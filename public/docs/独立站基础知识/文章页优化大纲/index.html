    一、前期调研（输入阶段）#

    1. 搜索意图与用户画像#

    • 收集文章主题相关的搜索意图
    • 明确目标读者是谁（B2B / 家长 / 教师 / 采购）
    • 使用AI辅助分析：
      • 用户为什么搜索这个词
      • 用户处于什么决策阶段

    👉 提示词方向： 如何用AI收集文章话题的搜索意图和目标读者画像？

    2. 学习该话题所有知识点#

    • 系统收集该主题的：
      • 基础知识
      • 延伸知识
      • 行业经验
    • 建立内容认知体系

    👉 提示词方向： 如何用AI学习一个话题的所有知识点？

    二、内容策划（结构阶段）#

    3. 策划文章结构#

    • 生成合理的文章大纲（H2 / H3结构）
    • 确保逻辑清晰、层次分明

    👉 提示词方向： 如何用AI生成合理的文章结构？

    4. 策划文章标题#

    • 不同类型标题：
      • 指南型（Guide）
      • 列表型（Top / Best）
      • 问题型（How / What）
    • 结合关键词优化

    👉 提示词方向： 如何用AI生成高点击率文章标题？

    5. 规划文章内容元素#

    • 明确文章包含哪些模块：
      • 定义
      • 优势
      • 应用场景
      • 实操建议
      • 案例
      • FAQ

    👉 提示词方向： 如何用AI规划文章内容元素？

    6. 竞品内容分析#

    • 收集Google排名靠前的文章
    • 拆解他们的：
      • 内容结构
      • 信息密度
      • SEO策略

    👉 提示词方向： 如何收集竞品文章内容元素，并分析排名因素？

    7. 生成文章大纲（升级版）#

    • 融合：
      • 用户意图
      • 竞品结构
      • 自身差异化

    👉 提示词方向： 如何结合AI策划高质量文章大纲？

    三、内容写作（输出阶段）#

    8. 写文章开头（极其重要）#

    • 直接切中：
      • 用户需求
      • 使用场景
      • 商业背景

    👉 提示词方向： 如何用AI写出高质量文章开头？

    9. 写文章正文#

    • 按模块逐步展开
    • 避免空话，提高信息密度
    • 强调：
      • 可执行建议
      • 实际经验

    👉 思考点：

    • 写给谁？（新手 / 专业 / 采购）
    • 是否解决实际问题？

    10. 写FAQ（10个以上）#

    • 覆盖：
      • 搜索问题
      • 转化问题
    • 部分问题用于引导成交

    👉 提示词方向： 如何生成同时适用于SEO + AI Search + 转化的FAQ？

    11. 写结尾（Final Thoughts）#

    • 总结核心价值
    • 引导行动（CTA）

    👉 提示词方向： 如何通过文章结尾提升转化率？

    四、SEO优化（强化阶段）#

    12. 布局长尾关键词#

    • 收集相关关键词
    • 分布在：
      • 标题
      • H2
      • 正文

    👉 提示词方向： 如何收集并布局长尾关键词？

    13. 提升文章专业度与AI可见性#

    • 强化：
      • 专业表达
      • 结构清晰度
      • 信息权威性

    👉 提示词方向： 如何通过AI提升文章：

    • 专业度
    • Google SEO排名
    • AI Search曝光
    • 转化率

    14. 内部链接布局#

    • 添加相关页面链接
    • 提升：
      • SEO权重
      • 用户停留时间

    👉 提示词方向： 如何设计文章内部链接结构？

    五、发布与优化（落地阶段）#

    15. WordPress发布#

    • 排版优化
    • 模块结构清晰
    • 图片+文字搭配

    16. 配图与视觉优化#

    • 选择合适图片
    • 提高点击率与停留时间

    👉 提示词方向： 如何选择文章配图以提高SEO与用户体验？

    17. 外链与权威性#

    • 添加高质量外链
    • 提升可信度

    👉 提示词方向： 如何选择高质量外链提升SEO？

    18. 发布前检查（Checklist）#

    • 标题是否优化
    • 关键词是否覆盖
    • 内容是否有深度
    • 是否解决用户问题
    • 是否具备转化引导

    👉 提示词方向： 文章发布前检查清单怎么做？

    六、最终目标#

    通过这套流程，实现：

    • SEO排名提升
    • AI Search曝光提升
    • 内容专业度提升
    • 页面转化能力提升

    👉 核心逻辑： 不是写文章，而是 用内容获取客户
